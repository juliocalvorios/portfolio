# The Calvo Chronicle

Personal portfolio website designed as a vintage newspaper. A creative approach to showcase frontend engineering skills.

![Portfolio Preview](/public/og-image.png)

## 🎯 About

This portfolio reimagines the traditional developer portfolio as a vintage newspaper, complete with:

- Editorial-style project presentations
- Traditional newspaper typography and layout
- Multiple sections: Front Page, Selected Works, About, Classifieds
- Fully responsive design
- Smooth animations and transitions

## 🛠 Tech Stack

- **React 18** - UI framework
- **Tailwind CSS** - Styling
- **Vite** - Build tool
- **Vercel** - Deployment (planned)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📁 Project Structure

```
src/
├── components/
│   ├── ui/
│   │   ├── Ornament.jsx      # Decorative diamond dividers
│   │   └── SectionRule.jsx   # Section title dividers
│   ├── Masthead.jsx          # Header with navigation
│   ├── FrontPage.jsx         # Main landing page
│   ├── SelectedWorks.jsx     # Project case studies
│   ├── About.jsx             # Developer profile
│   └── Classifieds.jsx       # Contact information
├── data/
│   └── projects.js           # Project data
├── App.jsx                   # Main application
├── index.css                 # Global styles
└── main.jsx                  # Entry point
```

## 📰 Sections

### Front Page
The main landing page featuring:
- Lead story with featured project

- Secondary stories grid

### Selected Works
Accordion-style project showcase with:

- Tech stack details

### The Developer
About section featuring:
- Personal background and journey
- Technical skills
- Education and experience

- Contact information
- Social links
